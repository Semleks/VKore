# 🚀 VKore
**Проект для автоматизации рутинных задач во ВКонтакте.**

Мощный, гибкий и безопасный инструмент, написанный на C# (.NET). VKore позволяет автоматизировать повседневные действия в социальной сети VK, работая как в ручном режиме (через консольное меню), так и в фоновом режиме (как демон на Linux).

---

## 💻 Установка и запуск (для разработчиков)
*Примечание: для обычных пользователей в планах отдельный релиз с удобным установщиком.*

### 1. Подготовка
Убедитесь, что у вас установлен [.NET SDK](https://dotnet.microsoft.com/download).

### 2. Клонирование репозитория
```bash
git clone https://github.com/Semleks/VKore.git
cd VKore
```

### 3. Как получить токен ВКонтакте (VK_API_KEY)
Для работы программы нужен токен доступа пользователя. Самый простой способ получить его с нужными правами:
 - Перейдите на сервис [VKHost](https://vkhost.github.io)
 - Выберите приложение (рекомендуется Kate Mobile или VK Admin).
 - Нажмите «Получить» и разрешите доступ к вашему аккаунту.
 - Вас перекинет на страницу с предупреждением от ВК. Скопируйте ссылку из адресной строки браузера.
 - В скопированной ссылке найдите фрагмент между access_token= и &expires_in. Это и есть ваш секретный токен.

### 4. Настройка ключа API
В целях безопасности токен от вашего аккаунта ВКонтакте не хранится в коде:
 - Найдите в корне проекта файл .env.example.
 - Скопируйте его и переименуйте копию в .env (в Windows/Linux просто создайте файл с таким именем).
 - Откройте .env и впишите ваш скопированный токен:
```
VK_API_KEY=ваш_длинный_токен_сюда
```

### 5. Запуск
Откройте проект в вашей IDE (Rider / Visual Studio) и запустите, либо используйте консоль.
